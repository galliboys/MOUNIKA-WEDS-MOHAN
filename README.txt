మౌనిక Weds మోహన్ — Wedding Invitation Website

1. ZIP ఫైల్‌ను Extract చేయండి.
2. audio ఫోల్డర్‌లో మీకు అనుమతి ఉన్న తెలుగు మంగళ వాయిద్యాల MP3 ఫైల్‌ను పెట్టండి.
3. MP3 ఫైల్ పేరును ఖచ్చితంగా mangala-vaadyam.mp3 అని పెట్టండి.
4. index.html ను బ్రౌజర్‌లో ఓపెన్ చేసి పరీక్షించండి.
5. పబ్లిక్ లింక్ కోసం GitHub లో కొత్త repository సృష్టించి, index.html మరియు audio ఫోల్డర్‌ను upload చేసి Settings → Pages లో Deploy from a branch → main → /(root) ఎంచుకోండి.

గమనిక:
- ఫోన్ బ్రౌజర్లు సాధారణంగా ఆటోప్లేను నిరోధిస్తాయి. అందుకే “ఆహ్వాన పత్రిక తెరవండి” బటన్ నొక్కిన తర్వాతే సంగీతం ప్రారంభమవుతుంది.
- ప్రస్తుతం పెళ్లి తేదీ, సమయం, వేదిక, పేర్లు మాత్రమే చేర్చబడ్డాయి. కుటుంబ పెద్దల పేర్లు లేదా పూర్తి చిరునామా ఇవ్వాలనుకుంటే HTMLలో మార్చుకోవచ్చు.
- మంగళ వాయిద్యాల MP3 ఈ ZIPలో లేదు; కాపీరైట్ అనుమతి ఉన్న ఆడియోను మాత్రమే ఉపయోగించండి.
